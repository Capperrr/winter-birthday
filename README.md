# For WINTER — 写给你的25岁

A birthday gift made for WINTER by her boyfriend. The glass navigation switches among About me, Home, and Destination. Home keeps the forest cover, with “For you,” above the moss-green WINTER title and a small dedication that makes the sender's perspective clear.

About me contains 22 lightly creased sticky notes arranged as the digits 25: 11 notes for each digit. Each has a unique paper texture, fold paths, curl position, placement and shadow; the two digits do not repeat the same rotations. The exact requested dedication appears underneath: “周琬婷，辛苦了。谢谢你过去的24年的坚韧。”

All notes start blank. Clicking a note opens an editor. Writing is stored only in the current browser under `winter-about-notes-v1`; it is not synchronized across devices or published into the Site source. Clearing a note's text and saving leaves it blank again. This update preserves the existing storage key and note IDs.

Destination uses its own dreamlike, AI-generated mountain / forest / meadow landscape. A closed paper envelope bears “25岁的周琬婷生日快乐”. The envelope is a static composition; opening, click behavior, letter contents and animation are intentionally deferred until the user specifies them. There is no misleading “open” button or pending interaction prompt.

Buildless HTML/CSS/JavaScript; deployable assets live in `dist/`. Responsive layouts, accessible tab controls, keyboard navigation, native note dialogs and reduced-motion preferences are supported. Navigation supports `#home`, `#about` and `#destination`, including browser back/forward. “只看风景” remains available on Home.
