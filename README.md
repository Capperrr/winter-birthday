# WINTER — 山野之间

A forest and Swiss Alpine personal space for WINTER. The glass navigation switches among About me, Home, and Destination. Home is the original forest cover with a small “I'm” above the larger moss-green WINTER title. Destination is an Alpine inspiration view.

About me contains 22 lightly creased sticky notes arranged as the digits 25: 11 notes for each digit. All start blank. Clicking a note opens an editor. Writing is stored only in the current browser under `winter-about-notes-v1`; it is not synchronized across devices or published into the Site source. Clearing a note's text and saving leaves it blank again.

Buildless HTML/CSS/JavaScript; deployable assets live in `dist/`. Responsive layouts, accessible tab controls, keyboard navigation, native note dialogs and reduced-motion preferences are supported. Navigation supports `#home`, `#about` and `#destination`, including browser back/forward. “只看风景” remains available on Home.
