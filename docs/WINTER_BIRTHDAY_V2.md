# WINTER Birthday 2.0

开始于远山和云海，穿进林中的私人展览，再沿湖泊、真实旅途和星空回到山野。压低蓝绿背景的亮度，暖色留给信、烛火、窗边和手写墨迹。

## 场景运行

`winter-film.js` 监听原站路由与对话框阶段。解码完成时换入同一个摄影机系统，滚动和指针只更新图层的位移和透视，原有内容与热区由原模块管理。静置时只有独立的雾、光或瀑布在低速运动。上一镜头随淡出退场，场景只在进入时加载。联机摄像头、光箱与画作导出会冻结背景运动。

用户点击「穿过石拱」时才载入 Three.js。镜头绕开近景，穿过有厚度的岩拱孔洞，到达补全后的云谷。其他大部分场景采用摄影分层和局部遮挡补全，保持 iPad 上的合成负担。关闭动效、节省流量或设备内存较少时使用完整高清静帧。WebGL 不可用时可以查看云谷静帧。

`tools/winter-v2/build-plates.py` 从原 ZIP 与五张补图生成已随代码提交的注册图层。读取另存的 `letter.png`、`childhood.png`、`studio.png`、`cosmos.png` 和 `home-back.png`。现有网页运行只需要 `dist/`。概念拼贴用于取色与构图参考。素材包的 Ordinary Days 和 Finale 底图二进制相同，运行时共用以减少下载。

## 验证

从仓库目录运行 `python3 -m http.server 4230 --directory dist`。运行 `node --test tests/*.test.cjs` 检查流程状态。已安装 Playwright 时可用 `WINTER_V2_URL=http://127.0.0.1:4230/ node tests/winter-v2.browser.cjs` 检查分层、素材加载、触控入口、WebGL 穿越与原始章序。设置 `WINTER_ENGINE=webkit` 可验证 WebKit，`WINTER_V2_RUN=portrait` 切换 13 英寸竖屏尺寸。
